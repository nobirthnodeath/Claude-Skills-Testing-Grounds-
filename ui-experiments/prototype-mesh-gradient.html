Prototype · throwaway · Round 8 · Graphite only

Graphite with a moving mesh gradient

The background is @mesh-gradient/core, a small WebGL library that moves four colors like a SwiftUI mesh gradient. The library has no chromatic aberration, so an SVG filter splits the image into red, green and blue and shifts them apart a few pixels. A dark layer fades in lower on the screen to keep the lists easy to read. Use the bar at the bottom to change palette, color split, speed and motion.
